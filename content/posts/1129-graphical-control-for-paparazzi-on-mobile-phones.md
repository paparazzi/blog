Three [ENAC](http://www.enac.fr/en/home) students have released a Graphical control application for Paparazzi on Mobile phones using Java Technologies, connecting via Bluetooth to the ground station. It is divided into 2 programs, one running on the ground station, and the other on the mobile phone. Check the [Ipodrom](https://wiki.paparazziuav.org/wiki/Ipodrom "Ipodrom") project page for more details.

\*Ipodrom is the french acronym for ***I**nterface **po**ur contrôler un **dro**ne sur un **m**obile*. It is the French UAV control interface on a mobile phone.

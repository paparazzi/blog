[![Penguin_logo](/wp-content/uploads/2015/07/Penguin_logo-150x150.gif)](/wp-content/uploads/2015/07/Penguin_logo.gif)The Paparazzi Development Team is pleased to announce the release of the **Paparazzi v4.0 stable** version.

After several months of testing and debugging, the [release preparation branch v3.9](http://wiki.paparazziuav.org/wiki/RepositoryStructure "RepositoryStructure") has been released as v4.0. See the [changelog](https://github.com/paparazzi/paparazzi/blob/v4.0/CHANGELOG.md) for an overview of new features and bugfixes.

If you are already using paparazzi with [Git](http://wiki.paparazziuav.org/wiki/Git "Git"), you can switch to this new branch with

**`git remote update && git checkout v4.0`**.

For new user, it will be the default branch when getting the [source code from Github](http://wiki.paparazziuav.org/wiki/Installation#Getting_the_Source_Code "Installation"). You can also download a [tarball](https://github.com/paparazzi/paparazzi/tarball/v4.0_stable) or [Zip file](https://github.com/paparazzi/paparazzi/zipball/v4.0_stable) of the v4.0\_stable source code.

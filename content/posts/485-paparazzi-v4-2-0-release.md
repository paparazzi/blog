[![Penguin_logo](/wp-content/uploads/2015/07/Penguin_logo-150x150.gif)](/wp-content/uploads/2015/07/Penguin_logo.gif)Just before the end of the world, discover **Paparazzi v4.2.0 stable** version.

Based on the last stable branch **v4.0**, this new release offers several improvements, especially the [total energy control](http://paparazzi.github.com/docs/latest/energy__ctrl_8c.html#details) developed by TUDelft. See the [changelog](https://github.com/paparazzi/paparazzi/blob/v4.2/CHANGELOG.md) for an overview of new features and bugfixes.

If you are already using paparazzi with [Git](http://wiki.paparazziuav.org/wiki/Git "Git"), you can switch to this new branch with

**`git remote update && git checkout v4.2`**.

For new user, it will be the default branch when getting the [source code from Github](http://wiki.paparazziuav.org/wiki/Installation#Getting_the_Source_Code "Installation"). You can also download a [tarball](https://github.com/paparazzi/paparazzi/tarball/v4.2.0_stable) or [Zip file](https://github.com/paparazzi/paparazzi/zipball/v4.2.0_stable) of the v4.2.0\_stable source code.

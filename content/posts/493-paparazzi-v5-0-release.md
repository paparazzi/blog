[![Penguin_logo](/wp-content/uploads/2015/07/Penguin_logo-150x150.gif)](/wp-content/uploads/2015/07/Penguin_logo.gif)For the opening of the Paris Air Show at Le Bourget, the Paparazzi Development Team is pleased to announce the release of the **Paparazzi v5.0 stable** version, including the support of the [Parrot AR.Drone2](http://ardrone2.parrot.com/). See this [page](http://wiki.paparazziuav.org/wiki/AR_Drone_2/getting_started "AR Drone 2/getting started") for more instructions.

See the [changelog](https://github.com/paparazzi/paparazzi/blob/v5.0/CHANGELOG.md) for an overview of new features and bugfixes.

See the [Release Upgrades](http://wiki.paparazziuav.org/wiki/Release_Upgrades "Release Upgrades") page for hints on configuration changes that may be required if you are moving to v5.0.0 from v4.2.0.

If you are already using paparazzi with [Git](http://wiki.paparazziuav.org/wiki/Git "Git"), you can switch to this new branch with

**`git remote update && git checkout v5.0`**.

For new user, you can download a [tarball](http://paparazzi.enac.fr/tarballs/paparazzi_v5.0.0_stable.tar.gz) or get the source code with

**`git clone https://github.com/paparazzi/paparazzi.git && git checkout -b v5.0 origin/v5.0`**.

[![Penguin_logo](/wp-content/uploads/2015/07/Penguin_logo-150x150.gif)](/wp-content/uploads/2015/07/Penguin_logo.gif)Paparazzi Development Team is pleased to announce the release of the **Paparazzi v5.2 stable** version with lots of new features and bugfixes.

See the [CHANGELOG](https://github.com/paparazzi/paparazzi/blob/v5.2/CHANGELOG.md) for an overview of new features and bugfixes. See the [Release Upgrades](http://wiki.paparazziuav.org/wiki/Release_Upgrades "Release Upgrades") page for hints on configuration changes that may be required if you are moving to v5.2 from v5.0.

If you are already using paparazzi with [Git](http://wiki.paparazziuav.org/wiki/Git "Git"), you can switch to this new branch with

**`git remote update && git checkout v5.2`**.

For new user, you can download a [tarball](https://github.com/paparazzi/paparazzi/releases/download/v5.2.0_stable/paparazzi_v5.2.0_stable.tar.gz) or get the source code with

**`git clone https://github.com/paparazzi/paparazzi.git -b v5.2`**.

[![Penguin_logo](/wp-content/uploads/2015/07/Penguin_logo-150x150.gif)](/wp-content/uploads/2015/07/Penguin_logo.gif)The Paparazzi Development Team is pleased to announce the release of a brand new version of Paparazzi; **v5.4**, giving you the option to enjoy lots of new features and improvements, happy new year!

If you're curious to know what has been added and improved you can, [go here for an overview](https://github.com/paparazzi/paparazzi/blob/v5.4/CHANGELOG.md). For your enjoyment and to *view* what all those changes look like, [click here](https://www.youtube.com/watch?v=QswDjzzDZHo).

If you are already using paparazzi with [Git](http://wiki.paparazziuav.org/wiki/Git "Git"), to enjoy all improvements you can switch to this new version via:

**`git remote update && git checkout v5.4`**.

If you are new to Paparazzi and want to join in flying it, you can you can simpy download a [tarball](https://github.com/paparazzi/paparazzi/releases/download/v5.4.0_stable/paparazzi_v5.4.0_stable.tar.gz) or get the source code via:

**`git clone https://github.com/paparazzi/paparazzi.git -b v5.4`**.

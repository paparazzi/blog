[![Penguin_logo](/wp-content/uploads/2015/07/Penguin_logo-150x150.gif)](/wp-content/uploads/2015/07/Penguin_logo.gif)The Paparazzi Development Team is pleased to announce the release of a brand new version of Paparazzi; **v5.6**, providing you with lots of new features and improvements!

If you're curious to know the specifics on what has been added and improved you can, [go here for an overview](https://github.com/paparazzi/paparazzi/blob/v5.6/CHANGELOG.md).

If you are already using paparazzi with [Git](http://wiki.paparazziuav.org/wiki/Git "Git"), to enjoy all improvements you can switch to this new version via:

**`git remote update && git checkout v5.6`**

If you are new to Paparazzi and want to join in flying with it, you can you can simply download a [tarball](https://github.com/paparazzi/paparazzi/releases/download/v5.6.0_stable/paparazzi_v5.6.0_stable.tar.gz) or get the source code via:

**`git clone https://github.com/paparazzi/paparazzi.git -b v5.6`**
